# Word-Dictionary
This is a single Page Application for a dictionary app.

# Features

1. Search for a word
2. Display pronunciation for the word
3. Save the words

# Built with

HTML
CSS
JavaScript
Dictionary API

# Usage 

Type a word into the search bar and click search to view it's meaning, pronunciation and save the word.
